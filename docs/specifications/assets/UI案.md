# UI 案（ブクログ風の本棚デザイン）

## 位置付け

[画面仕様書](./画面仕様書.md)の画面構成・操作・状態はそのままに、見た目と情報の見せ方だけを刷新する案。文言・数値・本文はすべて仮のサンプルで、確定は実データと操作確認後に行う。

操作できるモックは Claude のキャンバス上に作成済み（6 画面、左メニューで遷移可能）。このファイルはその内容を GitHub 上で共有するための文章版。

## デザイン方針

[ブクログ](https://booklog.jp/)のように「記録が棚に並ぶ」見せ方を取り入れる。要約を「本」、オープンチャットを「本棚」に見立てる。

| ブクログの要素 | 本アプリでの置き換え |
| :--- | :--- |
| 本の表紙が並ぶ本棚 | 要約を表紙カードで一覧表示。表紙の色はオープンチャットごと、日付と午前／午後を大きく表示 |
| 読書状況のタブ（読みたい／読み終わった など） | 状態タブ（すべて／ブックマーク／手編集済み／検索未反映） |
| カテゴリ・タグでの絞り込み、本棚内検索 | オープンチャットとタグのチップ絞り込み、本棚内検索 |
| 登録数などの統計 | 登録数・今月の要約数・検索反映済み数 |
| ランキング | 検索結果を順位つきで表示し、近さをバーで示す |
| 本の詳細ページ（表紙＋情報＋レビュー） | 要約の詳細（表紙＋メタ情報＋本文） |

> ブクログの実際の画面は取得できなかったため、構成の考え方を参考にしている。配色や細部は独自。

## 共通レイアウト

- 左に固定メニュー（本棚／トーク取込／要約実行／検索／設定）、右に内容。Windows の単一ウィンドウ、想定サイズ 1440×900。
- メニュー下部に状態表示（Codex 接続、検索未反映の件数）を常時表示する。
- 色は「紙」のような生成り背景に、アクセントの深いティール。
- フォントは Noto Sans JP（本文）、Noto Serif JP（表紙の日付）。
- ボタンなど操作部品は高さ 40〜44px 以上。

| 用途 | 色 |
| :--- | :--- |
| 背景 | `#F6F4EF` |
| カード・パネル | `#FFFFFF` |
| 罫線 | `#E4DFD4` |
| 文字 | `#1E2226` / 補助 `#5C626B` |
| アクセント | `#0E6A62`（淡色 `#DDEFEC`） |
| 注意 | `#FFF6DC`（文字 `#5E4300`） |
| 削除・エラー | `#B3261E` |
| 表紙（例） | `#0E6A62` `#2F4B7C` `#8C3B2E` |

## 画面ごとの案

### 1. 本棚（要約一覧・詳細）

```text
┌ メニュー ┬ 本棚                         登録数 / 今月 / 反映済み ┬ 詳細パネル ┐
│ 本棚     │ [すべて][ブックマーク][手編集済み][検索未反映]  [本棚内検索] │ オプチャ名 │
│ 取込     │ オプチャ: (すべて)(A)(B)(C)   タグ: [＋絞り込み]            │ 11/16 午前 │
│ 要約実行 │ ┌表紙┐ ┌表紙┐ ┌表紙┐ ┌表紙┐                              │ 状態バッジ │
│ 検索     │ │11/16│ │11/15│ │11/15│ │11/14│   表紙の下に見出し・タグ    │ 本文       │
│ 設定     │ └────┘ └────┘ └────┘ └────┘                              │ タグ       │
│          │ ...（下へスクロール）                                       │ 参考要約   │
│ 接続状態 │                                                            │ [開いて編集]│
└──────────┴────────────────────────────────────────────────────────────┴────────────┘
```

- 表紙カードに、オプチャ名・日付・午前／午後・メッセージ件数、ブックマークの印を表示する。
- 「手編集済み」「検索未反映」はカードの下にバッジで示す。
- 選択中の要約は表紙を枠で強調し、右の詳細パネルに本文・タグ・参考にした要約を表示する。
- 状態: 一覧／選択中／空／保存中／失敗（画面仕様書と同じ）。

### 2. 要約の詳細・編集

- パンくず（本棚 / オプチャ / 日付）。左に大きな表紙とメタ情報（対象時間、作成・更新日時、要約の元、検索への反映）。
- 右はタブ（要約／参考にした要約／タグ・メモ）。編集中は「保存すると手編集済みになり、自動更新から保護される」旨を表示する。
- 操作: 保存／キャンセル／AI の要約に戻す／再要約／削除。

### 3. トーク取込

- 大きなドロップ領域と「ファイルを選択」。選択後にファイル名と結果を表示する。
- 結果は 3 つの数（取り込んだ行／重複のため追加なし／読み取れなかった行）。不正行は `xxx行目：パースが失敗したため読み取れませんでした。` を行ごとに表示し、本文は含めない。
- 「同じ名前の別オープンチャットは同じものとして扱う」注意を常時表示する。
- 右に取込履歴（成功・一部失敗・失敗を色の点で区別）。

### 4. 要約実行

- 上部に中断ジョブの再開確認（再開する／破棄）。自動では再開しない。
- 左: ① 範囲を選ぶ（オプチャ、期間、午前／午後ごとの単位をチェック）／ ② 送信内容の確認（送信先、メッセージ件数、参考要約の期間・最大件数と選ばれた日付）。
- 右: 進み具合（単位ごとに完了・要約中・待機中、検索反映の状態）。処理中も他画面を使える旨を表示する。

### 5. 検索

- 大きな検索ボックス。入力文はこの PC 内で処理される旨を添える。
- 左に絞り込み（オプチャ、期間）。結果は順位・ミニ表紙・見出し・抜粋・近さのバー。結果を選ぶと要約詳細へ移る。
- 検索未反映の要約は結果に出ないことを明示する。

### 6. 設定

- カードを 2 列に配置: 要約用 AI（接続状態、CLI の場所、認証のやり直し。認証情報の中身は表示しない）／参考にする過去の要約（期間・最大件数）／データの保存先／検索データ（Embedding モデル、再生成）。

## 画面仕様書との対応

| 画面仕様書の項目 | この案での扱い |
| :--- | :--- |
| 左メニュー固定・右側切替 | 同じ（見た目のみ変更） |
| 取込のエラー表示文 | 同じ文言を行ごとに表示 |
| 中断ジョブの再開確認 | 要約実行画面の上部に表示 |
| 参考要約（7 日・最大 5 件） | 要約実行の確認欄と設定画面に表示 |
| 手編集の保護／AI の要約に戻す | 詳細・編集画面に注意書きとボタン |
| 検索未反映の扱い | 本棚のバッジ、検索画面の注記、メニューの状態表示 |
| 秘密情報は登録状態のみ表示 | 設定画面で「登録済み」とだけ表示 |

## 未決定・要確認

- 表紙のオプチャごとの色の決め方（自動割り当てか、利用者が選ぶか）。
- 本棚の表示切替（グリッド／リスト）を入れるか。
- 本棚内検索の範囲（見出し・タグ・本文のどこまで）。画面仕様書のキーワード検索の範囲と合わせて決める。
- 文言、日時・件数の表示形式、キーボード操作、取り消し操作（画面仕様書の「実装前に決めること」を引き継ぐ）。
- Embedding モデルは未設定のまま。
