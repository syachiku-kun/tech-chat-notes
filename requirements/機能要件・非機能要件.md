# 機能要件・非機能要件

## 機能要件


| 区分 | 機能 | 説明 | 状態 |
| :--- | :--- | :--- | :--- |
| 機能要件 | チャットを要約できる | 生成AIによるチャットの要約を行う | ☐ 未完了 |
| 機能要件 | チャットを分類できる | 生成AIによって要約された内容をユーザーがタグ付けできる | ☐ 未完了 |
| 機能要件 | ブックマークができる | 生成AIによって要約された内容をユーザーがブックマーク登録できる | ☐ 未完了 |
| 機能要件 | キーワード検索ができる | 生成AIによって要約された内容のキーワード検索ができる | ☐ 未完了 |
| 非機能要件 | 定期的な要約 | 生成AIによる要約を定期的に実行する | ☐ 未完了 |


----

* 凡例

| 区分 | 機能 | 説明 | 状態 |
| :--- | :--- | :--- | :--- |
| 機能要件 | ユーザーー登録 | メールアドレスとパスワードによる登録 | ☑ 未完了 |
| 非機能要件 | 可用性は99.99999 % | 驚きの数字 | ☐ 未完了 |
