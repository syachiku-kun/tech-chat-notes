# 機能要件・非機能要件

## 利用形態

本アプリケーションは公開 Web サービスではなく、利用者が配布物をダウンロードして各自の PC に配置し、ローカルで利用するデスクトップアプリとする。

## 機能要件

| 区分 | 機能 | 機能優先順位 | 説明 | 状態 |
| :--- | :--- | :--- | :--- | :--- |
| 機能要件 | アプリをインストールして利用できる | Must have（必須） | Windows 向け配布物をダウンロードし、各自の PC で起動できる | ☐ 未完了 |
| 機能要件 | チャットを要約できる | Must have（必須） | 取り込んだトークを生成 AI で要約する | ☐ 未完了 |
| 機能要件 | チャットを分類できる | Must have（必須） | 利用者が要約にタグを付けて分類できる | ☐ 未完了 |
| 機能要件 | ブックマークができる | Could have（あれば嬉しい） | 利用者が要約をブックマーク登録できる | ☐ 未完了 |
| 機能要件 | キーワード検索ができる | Could have（あれば嬉しい） | ローカルに保存された要約をキーワードで検索できる | ☐ 未完了 |
| 機能要件 | 意味検索ができる | Should have（重要） | 要約文の意味に近い内容をベクトル検索で探せる | ☐ 未完了 |
| 機能要件 | 保存された LINE トークを取り込める | Must have（必須） | LINE からテキスト形式（.txt）で保存したトーク履歴ファイルを利用者が選択し、アプリに取り込める | ☐ 未完了 |
| 非機能要件 | ローカルで動作する | Must have（必須） | アプリ本体と利用者データは各自の PC 上で動作・保存する | ☐ 未完了 |
| 非機能要件 | ベクトル DB をローカルで動作させる | Must have（必須） | ベクトル DB はアプリ内で動作し、サーバーの起動やクラウド DB を必要としない | ☐ 未完了 |
| 非機能要件 | 外部 AI への送信内容を明示する | Must have（必須） | 要約時にトーク本文を生成 AI へ、意味検索時に要約文や検索語を Embedding API へ送信することを説明する | ☐ 未完了 |
| 非機能要件 | 定期的な要約 | Must have（必須） | 生成AIによる要約を定期的に実行する | ☐ 未完了 |
| 非機能要件 | Windows で動作する | Must have（必須） | Windows 向けに配布する | ☐ 未完了 |

## 優先順位の凡例

`Must have（必須）> Should have（重要）> Could have（あれば嬉しい）> Won't have（今回は対象外）`の順。

## 運用上の前提

- LINE トークの取り込みは、利用者があらかじめ保存した .txt ファイルから行う。LINE アカウントへのログインや LINE API 接続は行わない。
- AI 要約と外部 Embedding API を使った意味検索にはインターネット接続が必要。利用する事業者・モデルは検討中。
